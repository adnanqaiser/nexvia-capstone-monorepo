
# Enterprise Multi-Benchmark & Collaborative Workspace (Capstone Projects)

This repository contains the official capstone project implementations for the Full-Stack Development Internship at Nexvia Technologies.

## 🚀 Projects Overview & Full Details

### 1. FS-01: Multi-Vendor E-Commerce Marketplace
- **Architecture:** Express, Node.js, Prisma ORM, and React (Vite).
- **Key Features:**
  - Dynamic multi-tenant vendor product catalog and management.
  - Secure checkout processing with automated 10% platform base commission deduction.
  - AWS S3 direct file/image upload capabilities and robust error handling.
  - Database cluster connection failover simulation fallbacks ensuring zero downtime.

### 2. FS-02: Real-Time Collaborative Workspace
- **Architecture:** Express HTTP/WebSocket dual-engine backend and React frontend.
- **Key Features:**
  - Integrated Yjs binary state synchronization hooks for live multi-peer document collaboration.
  - Real-time cursor concurrency updates and live presence indicators.
  - Dynamic split-pane document editing and version snapshot management.

---

## 🛠️ Tech Stack
- **Frontend:** React.js, Vite, Tailwind CSS, Lucide Icons, Yjs
- **Backend:** Node.js, Express.js, WebSockets, Prisma ORM
- **Database / Storage:** PostgreSQL, Supabase, In-Memory Fallback Engines
